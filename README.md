# Brazilian E-Commerce Sales & Customer Insights Analysis

## 📌 Project Overview

This project focuses on analyzing Brazilian e-commerce sales data to uncover meaningful business insights, understand customer purchasing behavior, evaluate sales performance, and identify opportunities for business growth.

Using the Brazilian E-Commerce Public Dataset by Olist, this analysis explores sales trends, customer demographics, payment preferences, product performance, order delivery, and customer satisfaction.

The goal is to transform raw e-commerce data into actionable insights that can support data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall e-commerce sales performance.
- Identify monthly and yearly sales trends.
- Understand customer purchasing behavior.
- Analyze customer distribution across Brazilian states.
- Identify top-performing product categories.
- Evaluate payment methods and installment preferences.
- Analyze order delivery performance.
- Understand customer satisfaction through review scores.
- Generate actionable business recommendations.

## 📂 Dataset Description

**Dataset:** Brazilian E-Commerce Public Dataset by Olist

**Source:** Kaggle

Dataset link: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains approximately 100,000 orders made between 2016 and 2018 across multiple marketplaces in Brazil.

### Key Dataset Tables

| Dataset | Description |
|---|---|
| Customers | Customer information and location |
| Orders | Order status and timestamps |
| Order Items | Product and sales details |
| Products | Product categories and attributes |
| Payments | Payment types and installment details |
| Reviews | Customer ratings and feedback |
| Sellers | Seller information and location |
| Geolocation | Brazilian geographical coordinates |
| Category Translation | Portuguese-to-English category mapping |
